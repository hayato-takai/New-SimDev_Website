# Previewing the site

From the project root (`d:\FINAL\New-SimDev_Website`):

```bash
npm run dev
```

Then open the URL it prints — usually **http://localhost:4321**

The page hot-reloads as you edit, so leave the server running. Press `Ctrl+C` to stop it.

## Other scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Dev server with hot reload — use this for previewing |
| `npm run build` | Builds the static site into `dist/` |
| `npm run preview` | Serves the built `dist/` to check the production output |

> First time on a fresh clone, run `npm install` before `npm run dev`.
